coppersmith攻击

标签（空格分隔）： RSA

本质

coppersmith实际上就是把“模 N 下的小根”问题，转化为“在某个格中找短向量”的问题；再用 LLL 找到短向量，从而把一个模等式提升成一个整数等式。
本质就是创造一个函数

f(x)=xn+a1xn−1+⋯+an−1x+c mod Nf(x) = x^{n} + a_1 x^{n-1} + \cdots + a_{n-1} x + c \bmod Nf(x)=xn+a1​xn−1+⋯+an−1​x+cmodN

然后求解一个 xxx 满足 f(x) mod N=0f(x) \bmod N = 0f(x)modN=0

稍微仔细研究一下

框定范围

要是硬解xxx肯定无法解答的，因为我们不知道这个NcN^cNc的ccc是多少。所以只能够先约定这个ccc的范围然后再解
ccc的值主要是取决于这几个值

c=⌈β2δ⋅log⁡nX⌉
c = \left\lceil \frac{\beta^2}{\delta} \cdot \log_n X \right\rceil
c=⌈δβ2​⋅logn​X⌉

开始构造格方便使用LLL

进而构造多项式族
对于 0≤i≤c0 \le i \le c0≤i≤c ，0≤j<d0 \le j < d0≤j<d ，定义

gi,j(x)=xj⋅Nmax⁡(0,m−i)⋅f(x)i
g_{i,j}(x) = x^j \cdot N^{\max(0, m-i)} \cdot f(x)^i
gi,j​(x)=xj⋅Nmax(0,m−i)⋅f(x)i

且这些多项式满足

gi,j(x0)≡0(modN)
g_{i,j}(x_0) \equiv 0 \pmod N
gi,j​(x0​)≡0(modN)

此时构造一个格为gi,j(x)g_{i,j}(x)gi,j​(x)的系数向量为行，组成一个格基BBB然后由于格中有个系数x0x_0x0​满足
h(x0)h(x_0)h(x0​)在x0x_0x0​的时候是NcN^cNc的倍数这样就可以用LLL来求解x。
