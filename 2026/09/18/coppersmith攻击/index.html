coppersmith攻击

标签（空格分隔）： RSA

本质

coppersmith实际上就是把“模 N 下的小根”问题，转化为“在某个格中找短向量”的问题；再用 LLL 找到短向量，从而把一个模等式提升成一个整数等式。
本质就是创造一个函数

$f(x)=x^{n}+a_1*x^{n-1}+...+a_{n-1}*x+c \quad mod \ N$

然后求解一个 $x$ 满足$f(x) \ mod \ N \ =0$

稍微仔细研究一下

###框定范围
要是硬解$x$肯定无法解答的，因为我们不知道这个$N^c$的$c$是多少。所以只能够先约定这个$c$的范围然后再解
$c$的值主要是取决于这几个值

$$
c = \left\lceil \frac{\beta^2}{\delta} \cdot \log_n X \right\rceil
$$

###开始构造格方便使用LLL
进而构造多项式族
对于$0 \le i \le c$ ，$0\le j < d$ ，定义
$$
g_{i,j}(x)=x^j*N^{max(0,m-i)}*f(x)^i
$$
且这些多项式满足
$$
g_{i,j}(x_0) ≡ 0 \ mod \ N
$$
此时构造一个格为$g_{i,j}(x)$的系数向量为行，组成一个格基$B$然后由于格中有个系数$x_0$满足
$h(x_0)$在$x_0$的时候是$N^c$的倍数这样就可以用LLL来求解x。

例题如下

这里我们可以看到只有$p$的高301位，以及$q$的低265位是清晰的
此时我们稍作化简
$$
N = p * q \
N = p * (k2^{265}+q_{low})\
N = pk2^{265}+pq_{low}
$$
此时我们对N整体取低265位可以得到
$$
N_{low}=p_{low}*q_{low} \ mod \ 2^{265}
$$
根据这个我们可以得到p的低265位，但是p一共有1024位，我们还差1024-(1024-725)-265=459位不知道，到这里我们可以直接进行构造coppersmith攻击来解出剩下的459位，但是我们可以进行爆破几位来更快解出来，我们选择爆破6位

然后我们爆破6位的同时跑coppersmith攻击即可获取flag
